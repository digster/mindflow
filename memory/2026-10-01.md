# 2026-10-01 — Marking an empty text box on screen

Branch `claude/gracious-hawking-nfk93n`, on top of 57a9687. No format change, so
no schema, CHANGELOG or version bump: the file and every export are unchanged.

## The ask

"If a textbox is not filled and then deselected, it doesn't leave any indication
that it exists, but it's there and shows the textbox again when clicked. There
should be some indication that the textbox object exists even if it's not typed
into."

## Cause

`textDefinition.draw` returned early on `text === ''`, and a `text` element has
transparent stroke and fill. The text tool creates the element before the editor
opens, and an untouched editor commits nothing, so the element stayed: selectable
across its 120 × 25 box, saved, counted in export bounds, and invisible.

## What changed

- **`src/render/shapes/text.ts`**: `blankTextMarker(el, render)` (pure, exported)
  decides whether to mark: the text is empty or whitespace-only (`/\S/`), not
  exporting, and not the element the editor is open on. It returns the
  placeholder word's layout when "Text" fits the box (0.5-unit slack for
  saved-geometry rounding), otherwise `word: null` for the outline alone.
  `draw` paints it: a dashed outline on the box edge (1 / zoom wide, 4 / zoom
  dashes) plus the word through `drawTextBlock`, all in `el.color` at 40% of the
  element's opacity. Visible text draws exactly as before. Whitespace-only text
  still goes through the old path when exporting, so PDF output is unchanged.
- **`src/model/registry.ts`**: `RenderContext.editingId: ElementId | null`.
  Needed because `TextEditor.displayed` hands the shape blank text during
  editing, so the shape cannot otherwise tell "empty" from "being edited".
- **`src/render/renderer.ts`**: `RendererOptions.editingId` callback, read once
  per frame. `app.ts` passes `store.getState().editingId`. The store already
  emits on `setEditing`, which repaints.
- **`src/render/export.ts`, `exportPdf.ts`**: pass `editingId: null`. They already
  set `exporting: true`, which this is the first shape to read.

# Follow-up — delete a text box closed empty

The user chose the other apps' behaviour: "let's follow what the other apps do
and delete the text box that's closed empty." Still no format change.

## What changed

- **Registry hook `isBlank?(el)`** plus `isBlankElement(el)` (`model/registry.ts`).
  `text` implements it with `isBlankText` (`!/\S/.test`), shared with the
  marker. Sticky, label and table types leave it out, so they survive being
  emptied. A hook, not a flag, because it depends on a field.
- **`TextEditor.create(element)`** (`ui/textEditor.ts`): adds the element with a
  *transient* `addElements`, opens the editor, and keeps a
  `Store.dirtyCheckpoint()` in `provisional`. `open` clears `provisional`.
- **`TextEditor.commit`**: `next` is the typed element if touched, else the
  element as is. `blank = regionKey === null && isBlankElement(next)`.
  - Provisional: a transient delete, then either `restoreDirty` and deselect
    (blank), or a recorded `Add <title>` of `next`. One step.
  - Existing and blank: rewind the typing if touched, then a recorded
    `deleteElements(..., 'Delete text')` and deselect. Applies untouched too,
    so a blank box from a file is deleted by opening and closing it.
  - Otherwise as before, including the untouched no-op guard.
- **`Store.dirtyCheckpoint()` / `restoreDirty(cp)`** (`store/store.ts`): a
  `settled` counter, incremented on recorded execute, undo, redo, `markSaved`,
  `setOrigin` and `markDirty`. `restoreDirty` refuses when it, or the board
  generation, changed. It emits `document` when the flag changes.
- **Controller**: new `onCreateText` option. `createTextAt` calls it, then
  sets the selection and tool. It no longer records the add itself. `app.ts`
  wires it to `textEditor.create`.
- The marker stays, with comments updated: it now covers blank text from files,
  pastes and undo. It was not removed, per the "ask before removing existing
  functionality" rule.

## Tests

- Unit: `dirtyCheckpoint.test.ts` (11) covers the clean round trip, an
